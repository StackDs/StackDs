# Local technology artwork

- `java.svg`: [Devicon 2.17.0, java-original.svg](https://github.com/devicons/devicon/blob/v2.17.0/icons/java/java-original.svg).
  Original blue cup and red steam. MIT license, reproduced below.
- `kitty.svg`: [Kitty's upstream logo](https://github.com/kovidgoyal/kitty/blob/master/logo/kitty.svg),
  source blob `6ca0eac4522ecce7dd8de07b435560dd38c41582`.
  See the [upstream license](https://github.com/kovidgoyal/kitty/blob/master/LICENSE).

These source SVGs are embedded directly into the generated badges. The Kitty
badge adds a light tile behind the artwork so its dark details remain visible.
