# Soy Bryan. En la terminal, Stack.

El nick viene de la mejor estructura de datos. Sí, la pila. **LIFO, sin discusión.**

Estudio Ingeniería Civil Informática en Chile. Me gusta entender cómo funcionan
las cosas por dentro, crear herramientas y hacer que Linux sea más accesible.
Si algo se puede automatizar, probablemente termine escribiendo un programa
para hacerlo.

**Software libre, curiosidad y unas cuantas horas frente a la terminal.**

## Proyectos que quiero que conozcas

### [Rookie Linux Develop](https://github.com/StackDs/Rookie-Linux-Develop)

Una entrada más amigable al mundo Linux: software de código abierto para crear
imágenes con aplicaciones de desarrollo preinstaladas en unos pocos clics.
Menos fricción para empezar a construir.

`Python` · `Linux` · `Open source`

### [Basic C Without Tears](https://github.com/StackDs/Basic-C-Without-Tears)

C, desde la teoría hasta la práctica, para quienes vienen de Python y quieren
acercarse al hardware. Un curso para perderle el miedo a la memoria y entender
qué ocurre debajo de las abstracciones.

`C` · `Memoria` · `Aprender haciendo`
